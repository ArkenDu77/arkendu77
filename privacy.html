Privacy Policy

Effective date: 1 October 2026

This policy explains how "The Quiet Machine" application (the "Application") handles information it obtains from Google. The Application is private software used by the owner of the YouTube channel The Quiet Machine to manage that channel. It is not offered to the public, and the only Google account that authorises it is the channel owner's own account.

1. Information the Application accesses

With the owner's permission, granted through Google's OAuth consent screen, the Application uses the YouTube Data API and the YouTube Analytics API to access the owner's own channel only:

  • the channel's identity (channel ID and title);
  • the channel's own videos, captions, thumbnails and playlists, which it uploads, updates and organises on the owner's instruction;
  • aggregated statistics about the channel's own videos: views, watch time, average view duration, audience retention, traffic sources and subscriber counts. These statistics are aggregated by YouTube and do not identify individual viewers.

The Application does not access any other user's account, private data, contacts, email or files.

2. How the information is used

  • to publish and organise the channel's own videos;
  • to display the channel's own performance to its owner on a private, password-protected dashboard;
  • to learn which kinds of episodes, titles and thumbnails serve viewers best, so that future episodes improve.

Google user data is used only to provide these functions for the channel owner. It is not used for advertising, it is not sold, and it is not used to build profiles of any person.

3. Storage and security

Authorisation tokens and statistics are stored on a private server controlled by the channel owner, readable only by the Application's own system account, behind encrypted connections (HTTPS) and password-protected access. Access tokens are never displayed in any web page or shared.

4. Sharing

Google user data is not sold or shared with third parties, except:

  • a publishing service that the owner uses to upload the channel's own videos to YouTube receives the video files and their titles, descriptions and playlist identifiers, for that purpose only;
  • aggregated statistics about the channel's own videos, which contain no personal data, may be processed by the owner's software providers to plan future episodes;
  • when required by law.

5. Retention and deletion

Channel statistics are kept while the channel is operated, to compare episodes over time. The owner can revoke the Application's access at any time at myaccount.google.com/permissions. Revocation immediately stops all further access, because the stored token no longer works; the owner can also delete the stored token and statistics from the server at any time.

6. Google API Services and YouTube

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

7. Viewers of the channel

People who watch The Quiet Machine on YouTube interact with YouTube, not with the Application. YouTube's own privacy policy applies to them. The Application never receives their personal information.

8. Changes and contact

Any change to this policy will be published on this page with a new effective date. Questions can be sent through the contact information on the channel's YouTube page: youtube.com/channel/UC0qe8XI7MvaB8UZqLcqRSIw.
